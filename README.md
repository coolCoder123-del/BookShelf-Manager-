📚 BookShelf Manager (Smart Library System)

A simple full-stack web application to manage books. You can add, update, delete, search books and track their reading status with a clean dashboard UI.

🚀 Features
➕ Add new books
✏️ Update book details
❌ Delete books
🔍 Search books by title or author
📊 Dashboard (Read / Reading / Unread count)
❤️ Mark favorite books
📖 View book details
🖥️ Card & Table view
🔐 Simple login system (localStorage)
🛠 Tech Stack

Frontend:

React.js
React Router DOM
Axios
Tailwind CSS

Backend:

Node.js
Express.js
MongoDB
Mongoose

⚙️ Setup Instructions
1. Clone project
git clone https://github.com/coolCoder123-del/BookShelf-Manager-.git
2. Backend setup
cd backend
npm install
npm start
3. Frontend setup
cd frontend
npm install
npm run dev
🔑 Environment Variables

Create .env file inside backend:

PORT=5555
MONGODB_URL=your_mongodb_connection_string
