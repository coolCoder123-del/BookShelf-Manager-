📚 BookShelf Manager (Smart Library System)

A full-stack MERN application to manage books efficiently with features like add, update, delete, search, and track reading status. It also includes a simple login system and a modern UI dashboard.

🚀 Features
➕ Add new books
✏️ Update book details
❌ Delete books
🔍 Search books by title or author
📊 Dashboard with stats (Read / Reading / Unread)
❤️ Mark favorite books
📖 View book details
🖥️ Table & Card view toggle
🔐 Simple login system (localStorage based)
🎨 Modern UI with background image styling
🛠 Tech Stack
Frontend
React.js
React Router DOM
Axios
Tailwind CSS
Backend
Node.js
Express.js
MongoDB
Mongoose

⚙️ Installation & Setup
1. Clone Repository
git clone https://github.com/coolCoder123-del/BookShelf-Manager-.git
2. Backend Setup
cd backend
npm install
npm start
3. Frontend Setup
cd frontend
npm install
npm run dev
🔑 Environment Variables

Create a .env file inside backend:

PORT=5555
MONGODB_URL=your_mongodb_connection_string
